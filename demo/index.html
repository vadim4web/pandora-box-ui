08Integration / DistributionRoot config · npm · CDN · CSS export

Конфиг проекта имеет приоритет. При обычной npm-установке ищутся файлы pandora.config.json и pandora.config.css в корне проекта. При наличии обоих CSS применяется последним. Внешний конфиг загружается без исполнения JS.

npm / Vite / Vue / React · после публикации
npm install pandora-box-ui
import 'pandora-box-ui/pandora-box-ui.css';

# после изменения config:
npx pandora-box-ui build --out ./src/pandora-box-ui.css
